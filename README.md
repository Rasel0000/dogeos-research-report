1.Project Overview
2.DogeOS is an EVM-compatible application layer built on Dogecoin. It aims to expand Dogecoin's utility by enabling developers to build smart contracts and decentralized applications using familiar Ethereum development tools. Just like Aptos and Sui
Official website: https://www.dogeos.com/
Official documentation: https://docs.dogeos.com/en/home
Ecosysten Link : https://www.dogeos.com/ecosystem 
2. Problem and Solution
Problem: Dogecoin's base layer is primarily designed for payments and does not natively offer the same general-purpose smart-contract development environment as EVM-compatible networks.
Solution: DogeOS provides an application layer with EVM compatibility, allowing developers to build smart contracts and applications using familiar Ethereum tools.
Potential users: Smart-contract developers, decentralized application teams, Dogecoin community members, and Web3 builders.
3. Key Features
EVM compatibility: Supports familiar Ethereum-compatible development workflows.
Smart contracts: Enables developers to create applications using Solidity and compatible tools.
Developer tooling: Documentation covers workflows involving tools such as Hardhat, Foundry, and ethers.js.
Testnet access: Developers can experiment with test tokens and deploy contracts on the DogeOS Chikyū Testnet.
Dogecoin ecosystem: Focuses on extending the utility of DOGE through applications and on-chain experiences.
